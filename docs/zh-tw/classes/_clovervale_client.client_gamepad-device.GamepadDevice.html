    Class GamepadDevice

    The gamepads connected to the browser, as Gamepads tells: each button pressed gives the command of the key it acts as, as findPadKey tells, unless a line is being typed, which no gamepad types in. The gamepads walk, turn and zoom only while nothing is open on the page. Nothing is read until the browser tells of a gamepad connected.
