    Interface MonsterKind

    The numbers of a kind of monster, which every monster of it shares, and what a monster of it can be up to.

    interface MonsterKind {
        biteDamage: number;
        biteInterval: number;

    Properties

    ReadonlybiteDamage

    biteDamage: number

    The health a bite of the monster that hits takes from a player.

    ReadonlybiteInterval

    biteInterval: number

    The shortest time from the start of one bite of the monster to the start of the next, in seconds.

    ReadonlychaseSpeed

    chaseSpeed: number

    The speed the monster chases a player and walks back home at, in meters per second.

    ReadonlyfightModes

    fightModes: readonly MonsterMode[]

    The modes in which a monster of the kind is in a fight, which a slash can hit, and which a player slashes at rather than talks to a villager.

    Optional ReadonlyfreeModes

    freeModes?: readonly MonsterMode[]

    For a kind a villager fights as, the modes in which the villager is free to be talked to; left out for a kind no villager fights as.

    ReadonlyhasWeapon

    hasWeapon: boolean

    Whether a monster of the kind holds a weapon now and then, which its state tells, as MonsterState.isArmed.

    Readonlyhealth

    health: number

    The health of a monster of the kind at full health.

    ReadonlyleashRange

    leashRange: number

    The farthest from the home of the monster a player can be for the monster to chase it, in meters. Beyond that, it gives up.

    ReadonlymaxSilver

    maxSilver: number

    The most silver coins a monster of the kind gives the player whose strike kills it, each number of coins from none up to it as likely as any other.

    Readonlymodes

    modes: readonly MonsterMode[]

    What a monster of the kind can be up to.

    ReadonlynoticeRange

    noticeRange: number

    The farthest the monster notices a player from, in meters.

    ReadonlyrespawnDelay

    respawnDelay: number

    How long after it dies the monster comes back to life at its home, in seconds, or, for a kind that never dies, how long one sits on the ground once beaten before it gets up.

    Optional Readonlywander

    wander?: MonsterWander

    How the monster wanders near its home, if it does, or left out for a kind that never wanders.
