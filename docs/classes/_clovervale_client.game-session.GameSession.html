    Class GameSession

    The play of the page with the game server, from before it connects until it is cut off: what is shown at every frame, what each message from the server changes, and what the inputs of the player of the page send.

    sendInput

    • sendInput(input: PlayerInput): boolean

      Gives the player of the page an input, which the prediction shows from now on and which is sent to the server, if the server has told the page of the player and the connection is still open.

      An interaction names the time of the server at which the world was as the page shows it at the step the interaction shows from, for the server to judge it on, if the settings have it so.

      Parameters

      • input: PlayerInput

        The input.

      Returns boolean

      Whether the player was given the input.

    showDisconnected

    • showDisconnected(): void

      Shows the page disconnected from the game server: it forgets its player and the world, and shows the village as it does before it connects.

      Returns void

    showFrame

    • showFrame(seconds: number): void

      Shows a frame: the controls of play are read, as PlayControls.update tells, and the lines due to be said are sent; every set of figures is shown as things are at the frame, as the settings have them shown, with what the panel reads of how the players are shown, the prompt of the space bar, and the camera on the player the settings have it follow, as it is shown; then the ending sheet, the time of day, the outlines of the obstacles and the music, and last everything moves on by the time since the last frame.

      Parameters

      • seconds: number

        The time since the last frame, in seconds.

      Returns void
