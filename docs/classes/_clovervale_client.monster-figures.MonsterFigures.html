    show

    • show(frame: FigureFrame): void

      Shows the monsters of a frame, and no others.

      Each monster stands where its state tells, facing the way it tells, and plays the clip of the action it tells, which starts over whenever the action count of the monster changes, with a health bar above it that shows its health against the full health of its kind, which is shown only while it is in a fight, as isFighting tells. A monster of a kind that holds a weapon, as MONSTER_MODELS tells, holds it only while its state tells it does, and plays its clips as holding it then. A monster without a model to show it with is left out.

      Parameters

      • frame: FigureFrame

        How things are shown at the frame, with the monsters as they are to be shown.

      Returns void

      Implementation of FigureSet.show
