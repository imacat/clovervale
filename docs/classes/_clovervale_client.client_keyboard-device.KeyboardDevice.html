    Class KeyboardDevice

    The keyboard: each key pressed gives the command of its code, unless a key that changes what it does is held with it; a walking key or an arrow key that play takes walks the player or turns the camera as long as it is held; and a plain Enter that nothing takes opens the box of the chat. While a line is typed, every key is for the box, the browser and the input method alone: the game neither acts on it nor keeps it from them.
