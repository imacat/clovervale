    Class DialogueBox

    The dialogue box of the player of the page: the dialogue it is in, as the server last told, and the reply the cursor is on.

    The box is open while the server tells of a dialogue, and it takes every key of the game then, so that the player neither moves nor does anything else, and leaves every other key to the browser. The up and down arrows move the cursor over the replies, stopping at the ends; Enter, or a click on a reply, answers with the reply, or ends a dialogue that offers none. Once the player has answered, the box waits for the server to tell what comes of it, and answers nothing more till then. The cursor starts on the first reply of every line.
