    Class ItemKeeper

    What there is to pick in a world: in the village, its patches of clover and what Toby has taken of them, in a cave, its chests and barrels, and anywhere, the items put down on its ground.

    pick

    • pick(player: Player, target: PickTarget): void

      Has a player pick something, if it has room for the item it is to get, if any; silver coins need no room, and come with what else a container holds. A four-leaf clover so picked is gone from its patch until it regrows CLOVER_REGROW_DURATION seconds later, an item picked up from the ground is gone from there, and a container so looted holds nothing from then on. A container that holds nothing gives nothing.

      Parameters

      • player: Player

        The player.

      • target: PickTarget

        What it picks, as it is now.

      Returns void
