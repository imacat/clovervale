    Class AuthoritativePlayer

    A player as the server moves it.

    The inputs of its peer come into effect in the order they were received, each no sooner than the next step, and no sooner than the player has taken as many steps with the previous input in effect as the input tells. So the player takes as many steps between two inputs as its peer did, whenever the inputs arrive in time for that.

    • step(
          step: number,
          map: "village" | "cave",
          isHeld: boolean,
          monsters: readonly MonsterState[],
      ): StampedInput[]

      Moves the player one step of the simulation forward, in a map, with the inputs whose turn has come in effect.

      An input that has waited for INPUT_WAIT_LIMIT steps comes into effect whether its turn has come or not. A player held in place takes the inputs in as well, but from the step on it wants neither to move nor to interact, whatever they tell, as if it had been told so.

      Parameters

      • step: number

        The number of the step, as the server counts them, which tells where Toby is.

      • map: "village" | "cave"

        The map the player is in.

      • isHeld: boolean

        Whether the player is held in place at the step.

      • monsters: readonly MonsterState[]

        The monsters in the map, which tell whether the player slashes rather than talks to a villager.

      Returns StampedInput[]

      The inputs that came into effect at the step, in the order they did.
