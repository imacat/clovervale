    Function interpolatePlaced

    • interpolatePlaced<T extends Placed>(
          before: readonly T[],
          after: readonly T[],
          fraction: number,
          span: number,
          findLeeway?: (item: T) => number,
      ): T[]

      Places everything part of the way from where one snapshot tells to where the next tells, turned likewise, the shorter way around. Anything that has moved farther than it can walk in the time between them, and than it can have been moved otherwise, stays where the earlier one tells.

      Type Parameters

      • T extends Placed

      Parameters

      • before: readonly T[]

        Everything as the earlier snapshot tells.

      • after: readonly T[]

        Everything as the later snapshot tells.

      • fraction: number

        How much of the time between them has passed, from 0 to 1.

      • span: number

        The time between them, in milliseconds.

      • OptionalfindLeeway: (item: T) => number = ...

        How far beyond its walk each thing can have been moved in that time, in meters, by where the later snapshot tells it is. Nothing is by default.

      Returns T[]

      Everything the earlier snapshot tells, in its order, and otherwise as it tells.
