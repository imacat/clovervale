    • startServer(
          target: string | number,
          day: DayCycle,
          limits?: PeerLimits,
      ): Promise<RunningServer>

      Starts a game server.

      Every peer that connects gets a player of its own in the village, which it is welcomed with and steers with its messages, and which leaves the world it is in when the peer disconnects. The welcome also tells the peer how the day goes. A peer that sends anything but well-formed client messages, or inputs that are not numbered upward, or more inputs than can wait for their turn, is disconnected. A line or a phrase a peer has its player say is heard as Realm.receiveChat tells. Every peer is sent what Realm.composeMessages composes for its player, again and again as the simulation of the worlds goes on: snapshots of the world its player is in and the events that happen there. Whenever the map its player is in changes, the peer is first told which map that is. A slash that names the time of the world its peer showed is judged on the world as it was then, as far as the world allows.

      A peer that sends a message longer than any client sends, or anything that breaks the WebSocket protocol, is disconnected, and so is a peer that does not answer the pings of the server in time, or that falls too far behind with what it is sent, as the limits tell.

      A Unix socket file is created for its owner and its group to connect to. A socket file that nothing listens on anymore is replaced.

      Parameters

      • target: string | number

        The TCP port to listen on, or 0 for any free port, or the path of the Unix socket file to listen on.

      • day: DayCycle

        How the time of day goes, counted from step 0 of the simulation.

      • Optionallimits: PeerLimits = DEFAULT_PEER_LIMITS

        How long the server bears with its peers, or as long as a server on the Internet does by default.

      Returns Promise<RunningServer>

      The running server.

      Throws

      If the server cannot listen there: the port is taken, another server is listening on the socket file, or the path of the socket file is taken by something that is not a socket.
